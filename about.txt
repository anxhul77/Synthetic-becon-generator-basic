SECTION 1: OVERVIEW AND SYSTEM PURPOSE
--------------------------------------------------------------------------------
The Synthetic Optical Beacon Image Generator is a physically-grounded, modular software engine designed to synthesize realistic two-dimensional optical receiver image frames containing subpixel-positioned optical beacon signals (such as laser spots or LED markers). Developed specifically for researching AI-based and classical virtual camera tracking systems for Free Space Optical Communication (FSOC) terminal coarse alignment, the generator accurately models the forward physical image formation chain of an optical receiver. In mobile FSOC scenarios, optical terminals must establish and maintain precise line-of-sight tracking under platform dynamics, atmospheric propagation losses, background radiance, and sensor noise. Evaluating tracking algorithms in real-world flight or field trials is extremely costly and lacks absolute subpixel ground truth. This synthetic generator solves that challenge by producing high-fidelity image arrays alongside an immutable 27-field double-precision ground-truth metadata dictionary for every frame. The engine enables controlled, repeatable experimentation across arbitrary Signal-to-Noise Ratios (SNR), atmospheric distances, background radiance levels, point spread function shapes, and subpixel target coordinates.


SECTION 2: MATHEMATICAL AND PHYSICAL FORMULAS
--------------------------------------------------------------------------------
The generator simulates discrete physical image formation using rigorous optical, geometric, atmospheric, background, and noise equations.

1. Governing Forward Image Formation Equation:
   The spatial intensity I(x, y) at pixel coordinate (x, y) is calculated by evaluating:
   I(x, y) = Quantize( Clip( A_recv * PSF(x - x0, y - y0) + B(x, y) + N(0, sigma_n^2), 0, I_max ) )
   Where A_recv is the attenuated peak beacon intensity, PSF(x - x0, y - y0) is the normalized point spread function centered at continuous subpixel centroid (x0, y0), B(x, y) is the background radiance field, N(0, sigma_n^2) is additive white Gaussian noise, Clip constrains values to the dynamic range [0, I_max], and Quantize converts values to integer counts (for uint8 mode) or passes them as float64 values.

2. Pinhole Camera Geometry and Angular Coordinates:
   The optical receiver geometry follows an ideal pinhole camera model defined by intrinsic matrix K:
   K = [[fx, 0, cx], [0, fy, cy], [0, 0, 1]]
   For an image sensor of width W and height H, the horizontal and vertical Fields of View (FOV) in degrees are dynamically derived as:
   FOV_x = 2 * arctan( W / (2 * fx) ) * (180 / pi)
   FOV_y = 2 * arctan( H / (2 * fy) ) * (180 / pi)
   The mapping from subpixel coordinates (u, v) to optical direction angles (theta_x, theta_y) in radians relative to the optical axis is given by:
   theta_x = arctan( (u - cx) / fx )
   theta_y = arctan( (v - cy) / fy )
   Conversely, the forward projection of direction angles (theta_x, theta_y) to pixel coordinates (u, v) is calculated via:
   u = cx + fx * tan(theta_x)
   v = cy + fy * tan(theta_y)

3. Point Spread Function (PSF) Models:
   The spatial distribution of focused optical energy on the sensor array is modeled using 2D Gaussian point spread functions:
   - Isotropic 2D Gaussian PSF:
     S(x, y) = A_recv * exp( -((x - x0)^2 / (2 * sigma_x^2) + (y - y0)^2 / (2 * sigma_y^2)) )
     For rotationally symmetric optics, sigma_x = sigma_y = sigma.
   - Rotated Anisotropic 2D Gaussian PSF:
     To model astigmatism or asymmetrical beam deformation rotated by angle theta:
     x_rot = (x - x0) * cos(theta) + (y - y0) * sin(theta)
     y_rot = -(x - x0) * sin(theta) + (y - y0) * cos(theta)
     S(x, y) = A_recv * exp( -(x_rot^2 / (2 * sigma_x^2) + y_rot^2 / (2 * sigma_y^2)) )

4. Atmospheric Attenuation (Beer-Lambert Law):
   Optical power loss over link propagation range L (in kilometers) with atmospheric attenuation coefficient alpha (in 1/km) is governed by Beer-Lambert law:
   Transmittance T = exp( -alpha * L )
   Received Peak Intensity A_recv = A0 * T
   Where A0 is the unattenuated source peak amplitude.

5. Background Illumination Models:
   - Uniform Ambient Background:
     B_uniform(x, y) = B0 (spatial baseline radiance)
   - Linear Spatial Gradient Background:
     To model stray sunlight or glare across the receiver lens:
     B_gradient(x, y) = max( 0, B0 + a * x + b * y )
     Where a and b denote horizontal and vertical intensity gradient slopes.

6. Sensor Readout Noise and SNR Definition:
   Thermal and readout noise in the photodetector pixel array is modeled as Additive White Gaussian Noise (AWGN):
   N ~ Normal( 0, sigma_n^2 )
   Peak Signal-to-Noise Ratio (SNR) in decibels is defined relative to the peak received beacon intensity A_recv:
   SNR_dB = 20 * log10( A_recv / sigma_n )
   Solving for noise standard deviation sigma_n yields:
   sigma_n = A_recv * 10^( -SNR_dB / 20 )

7. Quantization and Dynamic Range Clipping:
   Image arrays are clipped to dynamic range [0, 2^b - 1] for b-bit depth.
   - For 8-bit mode (uint8): Pixel values are rounded to integers in [0, 255].
   - For 64-bit mode (float64): Pixel values retain full double-precision floating-point values without integer rounding or dynamic range truncation.


SECTION 3: SOFTWARE ARCHITECTURE AND LIBRARIES USED
--------------------------------------------------------------------------------
The codebase is structured in a clean, object-oriented modular architecture using Python 3.11.9:

1. Modular Component Breakdown:
   - generator/camera.py: Implements PinholeCamera class encapsulating intrinsic matrix K, dynamic FOV formulas, and bidirectional subpixel/angular transformations.
   - generator/psf.py: Implements GaussianPSF and EllipticalGaussianPSF classes providing normalized 2D spatial intensity profiles.
   - generator/atmosphere.py: Implements AtmosphericModel computing Beer-Lambert attenuation and optical transmittance.
   - generator/background.py: Implements UniformBackground and GradientBackground generating 2D spatial background matrices.
   - generator/noise.py: Implements GaussianNoise calculating exact noise standard deviation sigma_n and adding Gaussian noise.
   - generator/beacon.py: Implements BeaconSignal combining subpixel positioning, peak amplitude, and optical PSF into pixel arrays.
   - generator/generator.py: Implements SyntheticBeaconGenerator orchestrating the complete pipeline and managing deterministic RNG state via numpy.random.default_rng(seed).

2. Core External Libraries and Roles:
   - NumPy (v1.26+): Used as the primary numeric engine for 2D array generation, spatial meshgrid evaluation, vectorized Gaussian exponential calculations, matrix intrinsics, and pseudo-random number generation.
   - SciPy: Utilized for non-linear curve fitting (scipy.optimize.curve_fit) during PSF verification and statistical moment computations (skewness and kurtosis) during noise distribution validation.
   - Pandas: Employed for structuring validation results into relational data tables and exporting automated CSV validation reports.
   - Matplotlib: Used for generating diagnostic plots including noise probability density histograms, SNR linearity verification curves, quantization RMSE bar charts, and boundary truncation error graphs.
   - PyYAML: Used for declarative configuration loading from config/generator_config.yaml and config/experiments.yaml.
   - Pytest (v9.1.1): Used for running 36 automated unit test cases across all software sub-modules.
   - UUID (Standard Library): Used for generating universally unique identifiers (UUIDv4) for every synthesized frame.

SECTION 5: EMPIRICAL RESULTS AND FINAL VALIDATION STATUS
--------------------------------------------------------------------------------
1. Reconciliation of Minor Discrepancies:
   During independent auditing, three minor implementation nuances were identified and resolved:
   - Configuration Discrepancy: Runtime validation scripts were updated to automatically serialize the exact configuration used to results/exp00/config_used.yaml, ensuring 100% configuration consistency.
   - PSF Boundary Truncation: Diagnostic testing revealed that positioning beacons within 3*sigma (6 pixels) of image borders causes optical PSF clipping, introducing centroid bias up to 0.67 pixels. A mandatory 6-pixel valid-FOV border margin requirement was established for all subsequent tracking benchmarks.
   - Trial Count Ambiguity: Clarified configuration definitions between position benchmarks (10 positions) and total frame trials (20 trials across 2 tracking algorithms).
